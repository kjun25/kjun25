# 집눈

부동산을 처음 보는 사람을 위한 곳.

호갱노노나 KB부동산은 이미 아는 사람에게 좋은 도구다. 처음 집을 알아보는 사람에게는
화면에 뜬 말부터 모른다. 집눈은 **그 벽을 넘기 전까지의 기간**을 맡는다.
넘고 나면 기존 서비스로 가면 된다.

수학눈이 수학 개념에 한 일을 부동산 용어에 한다 — **읽어서 외우는 대신 당겨 보고 알게 한다.**

## 지금 있는 것

| 쪽 | 무엇 |
|---|---|
| `/terms` | 용어 5개. 슬라이더를 당기면 숫자가 그 자리에서 바뀐다 |
| `/find` | 지금 어떤 때인지 고르면 조건이 미리 켜지고, 값과 지역을 정하면 맞는 동네가 나온다 |
| `/webtoon` | 매주 한 편씩 올리는 만화 |

용어는 전세가율, 갭, LTV, DSR, 전용면적. 처음 집을 볼 때 가장 자주 막히는 것부터 골랐다.

## 돌려 보기

```bash
npm install
npm run dev      # http://localhost:4321
npm test         # 계산이 맞는지 (18개)
npm run build    # dist/ 에 정적 파일
```

## 배포

Cloudflare 정적 자산으로 올린다. 서버비 0원이다.

```bash
npx wrangler deploy
```

`wrangler.jsonc`가 `dist/`를 그대로 올린다. `git push` 로 자동 배포를 붙이면 손이 더 준다.

## 만화 올리는 법

1. 그림을 `public/webtoon/<회차이름>/` 에 넣는다 (`1.png`, `2.png` ...)
2. `src/content/webtoon/<회차이름>.md` 를 만들고 아래를 채운다

```yaml
---
title: 전세가율이 뭔지 몰랐던 날
episode: 1
date: 2026-08-16
summary: 부동산에서 들은 말을 하나도 못 알아들었던 이야기.
terms: [jeonse-ratio, gap]
panels:
  - src: /webtoon/01-jeonse-ratio/1.png
    alt: 부동산 사무실에 앉아 있는 사람. 중개사가 전세가율 이야기를 꺼낸다.
---
```

3. `git push`

**`alt`는 반드시 적는다.** 두 가지 이유다. 그림을 볼 수 없는 사람이 이 만화를 읽는
길이 그것뿐이고, 검색엔진은 그림 속 글자를 읽지 못해서 만화만 올리면 그 회차는
검색에 잡히지 않는다. `alt`와 본문 글이 검색으로 들어오는 길이다.

`terms`에 용어를 적어 두면 만화 아래에 그 용어로 가는 링크가 자동으로 붙는다.
**만화 → 용어 → 동네 찾기**로 이어지는 길이 한 사람이 여러 쪽을 보게 만든다.

## 자료에 대해 — 지금은 임시값이다

`src/lib/find/regions.ts` 의 숫자는 **전부 채워 넣은 임시값이다. 실제 조사값이 아니다.**
동 이름만 실제 대전의 동이다. 화면에도 그렇게 밝히고 있다.

지금 이 파일이 하는 일은 두 가지다. 계산과 화면이 끝까지 도는지 확인하는 것,
그리고 실제 자료가 들어올 자리의 모양을 정하는 것.

실제 값은 전부 무료로 공개돼 있다.

| 값 | 어디서 |
|---|---|
| 집값 | 국토교통부 실거래가 (공공데이터포털) |
| 지하철 | 국가철도공단 역사 위치 |
| 버스 | 대전광역시 버스 정류장 정보 |
| 커피숍·편의점 | 소상공인시장진흥공단 상가업소 정보 |
| 학교 | 학교알리미 |
| 공원 | 전국 도시공원 표준데이터 |

값을 채우면 그 항목의 `provenance`를 `'confirmed'`로 바꾸고, 전부 바뀌면
`dataIsProvisional`을 `false`로 둔다. 화면의 안내 문구가 같이 사라진다.

## 지켜야 할 것

**화면 규칙**

- 이모지를 쓰지 않는다. 표시가 필요하면 인라인 SVG로 그린다
- 두 색 그라디언트를 쓰지 않는다
- 어려운 외래어를 쓰지 않는다. "역세권"이 아니라 "지하철역이 걸어갈 거리에"
- 글자와 배경의 밝기 차이를 4.5:1 이상으로 둔다
- 초보자용일수록 화면이 조용해야 한다

**정보는 없애지 말고 접는다.** 처음 화면에 안 보이기만 하면 된다.
다 빼 버리면 "쉽다"가 "볼 게 없다"가 되고, 그러면 한 번 오고 끝난다.
보는 사람이 조금씩 자라는 걸 따라갈 수 있어야 한다.

**조언하지 않는다.** "지금이 매수 타이밍" 같은 문장은 쓰지 않는다.
계산으로 나오는 사실만 쓰고 출처를 밝힌다. 이유는 두 가지다 —
검색엔진은 돈이 걸린 주제에서 신뢰도를 까다롭게 보고, 신규 사이트가 투자 조언으로
상위에 오르기는 매우 어렵다. 그리고 조언은 민원과 책임을 부른다.

**모르는 것을 아는 척하지 않는다.** `score.ts`에서 자료가 없는 조건은 0점이 아니라
`null`이다. "안 맞는 동네"와 "아직 자료가 없는 동네"는 다르다.

## 앞으로

1. 용어를 늘린다. 하루면 하나 만든다. 가장 빨리 검색에 잡히는 쪽이다
2. 대전 실거래가를 붙여 `regions.ts`의 값을 실제 값으로 바꾼다
3. 단지별 쪽을 만든다. 이때부터는 정적으로 굽지 못한다 —
   Cloudflare 무료 플랜의 정적 자산 상한이 20,000개라, Worker에서 그때그때 그리고
   Cache API로 받쳐야 한다
4. 매일 신고가·신저가 쪽을 만든다. 검색이 잡히는 6~12개월을 버티는 건 이쪽이다

## 만든 구조

```
src/
  lib/
    format.ts          돈·비율·상환액 (순수 함수)
    terms.ts           용어 목록
    find/
      types.ts         자료 모양
      keywords.ts      고를 수 있는 조건 + 상황별 기본값
      regions.ts       동네 자료 (지금은 임시값)
      score.ts         맞춰 보는 계산 (순수 함수)
  components/react/    만지는 조각들
  pages/               쪽
test/                  format 과 score 시험
```

`score.ts`를 순수 함수로 떼어 둔 이유는 그 결과가 모든 쪽에 그대로 나가기 때문이다.
여기가 틀리면 모든 쪽이 한꺼번에 틀린다. 그래서 따로 시험한다.
